# Customer Value Prediction

The goal is to predict a customer’s purchase value based on their multi-session behavior across digital touchpoint

#### Approach
* Performed Exploratory Data Analysis
* Visualized features
* Performed Feature Engineering and Preprocessing
* Build different regression models
* Compared performance metrics

#### Models
* Random Forest Regressor
* LGBM Regressor
* Histgradient Boosting Regressor
* XGBRegressor

#### Final Result

Achieved $R^2$ score > 0.60
